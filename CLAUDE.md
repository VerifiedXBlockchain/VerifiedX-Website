# VerifiedX Website

Astro + Tailwind marketing site for verifiedx.io. Docs links point at docs v2 (docs.verifiedx.io); only `/` has a Spanish page (`translatedPaths`).

## Ship

- Non-prod: push a branch and open a PR to `main`; Vercel builds a preview for every PR. Push branches freely and give the preview URL.
- Prod: Vercel deploys `main` to verifiedx.io. There is no auto-merge, and merging is Tyler's call. PRs that describe a release wait until that release is live on mainnet.
